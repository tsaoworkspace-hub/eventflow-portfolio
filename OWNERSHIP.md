# Project ownership and portfolio scope

This repository is a standalone portfolio extraction from the collaborative **SneakerMarket / 酷客 Kicks** course project.

## Authorship represented here

曹志宗（Frank Tsao）independently implemented the front-end and back-end work for these feature areas in the original team project:

- event administration and public event presentation;
- member calendar, event following, and reminders;
- notification creation, delivery, read state, preferences, subscriptions, logs, and dashboard;
- Google Calendar connection and synchronization logic.

## Changes made for this public-ready edition

The portfolio edition adds small adapters needed to run those modules outside the original team repository:

- minimal member, brand, category, and product models;
- H2 in-memory database configuration;
- fictional demo data and an explicitly labelled demo session;
- standalone routing, navigation, configuration, and documentation;
- Windows-compatible Mockito test-agent setup.

These adapters do not imply authorship of the original team members' authentication, commerce, auction, or order modules. Those modules are intentionally excluded.

## Before publishing

The original repository belongs to a team workspace and is private. Before making this extraction public, confirm that doing so complies with the team's agreement and any course or organization rules. No third-party credentials, customer data, or private repository history should be included.
